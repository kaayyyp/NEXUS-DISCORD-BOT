# NEXUS DISCORD BOT

**A comprehensive Discord bot with moderation, music, tickets, voice management, giveaways, and more.**

## 🎯 Features

- 🔧 **Setup & General** - Server configuration and prefix management
- 🔨 **Moderation** - Ban, kick, warn, jail, timeout, and more
- 🎫 **Tickets** - Support ticket system with claims and transcripts
- 🔊 **VoiceMaster** - Dynamic voice channel creation and management
- 🎵 **Music** - Music player with queue management
- 🎉 **Giveaway** - Advanced giveaway system with customization
- ⚙️ **Configuration** - Auto-responders, reaction roles, logging, and more

## 📋 Requirements

- Python 3.8+

## 🚀 Installation

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Configure `.env` with your bot token
4. Run: `python main.py`
